# ML Classification - Breast Cancer Wisconsin

University Machine Learning project focused on binary classification using the
Breast Cancer Wisconsin (Diagnostic) dataset.

## Objective

Implement a Gaussian Naive Bayes classifier in Python and compare its performance
with:

- scikit-learn GaussianNB
- WEKA NaiveBayes

## Dataset

Breast Cancer Wisconsin (Diagnostic), UCI Machine Learning Repository.

Target:

- B = Benign
- M = Malignant

## Planned workflow

1. Dataset analysis
2. Feature preprocessing
3. Train/test split
4. Custom Gaussian Naive Bayes implementation
5. Performance evaluation
6. scikit-learn comparison
7. WEKA comparison
8. Final analysis and conclusions
